# Snack Prompt Reference

## Source

- URL: https://snackprompt.com/
- Reviewed: 2026-08-17
- Role: UX and taxonomy inspiration only.

## Observed ideas

Snack Prompt presents a prompt marketplace organized by categories, use cases, integrations, tools, and curated lists. These ideas informed EvoPlatform's taxonomy, catalog-entry, and collection contracts.

## Adoption boundary

EvoPlatform does not copy prompts, proprietary content, rankings, or user-generated material from the source. The source is not treated as evidence of quality, safety, licensing, or production readiness. Every catalog entry must have its own evaluation record, provenance, and license metadata.
